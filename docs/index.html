Everything you need. Nothing you don't.

Full access to OEM firmware registers without the memory leaks, ads, and login prompts.

Thermal & Power Modes

Instantly toggle Eco, Balanced, and Performance / Turbo modes with one click, a global hotkey, or vendor key. Remembers custom fan curves and wattage per profile.

7-Point Fan Curves

Drag seven temperature-to-RPM control points, customize hysteresis ramp delays, set safety floors, or toggle Max Fan with smart auto-cool off after 60°C.

GPU MUX & Power Gains

Switch between Hybrid, Discrete (direct dGPU MUX), and iGPU-only modes. Boost CPU+GPU power budget (+0W to +15W) and configure NVIDIA Dynamic Boost levels.

RGB Keyboard Lighting

Interactive visual keyboard canvas. Customize 4-zone or per-key illumination with Static, Breathe, Cycle, Wave animations, or delegate to Windows Dynamic Lighting.

Optional PawnIO Driver

Zero mandatory drivers. Need direct register access? Install the open-source signed PawnIO driver with one click to read raw CPU package sensors and bypass EC fan limits.

Tray Sensor Dashboard

Live CPU/GPU temps, package wattage, fan RPMs, chassis thermal probe, and battery discharge rates directly rendered in the Windows taskbar system tray.

Direct Firmware Communication

Seal communicates directly with your laptop's low-level ACPI WMI and BIOS mailboxes—the exact interface vendor utilities use, without their runtime baggage.

  • HP ACPI WMI hpqBIntM (0x1A modes, 0x27 max fan, 0x2E curves, 0x29 power, 0x52 MUX)
  • ASUS ACPI WMI ASUS_WMI (Throttle Thermal Policy 0/1/2, Fan Boost, Fan RPM Tachs)
  • Acer Gaming WMI Acer_WMIData & EC (Quiet, Normal, Turbo, CoolBoost max fans)
  • WMI Events hpqBEvnt (OMEN key intercepted and remapped)

How to verify your laptop or report issues

Help expand our verified list. Testing takes less than 3 minutes.

Finding your board ID

Open Seal and look at the header in Settings, or run this quick PowerShell command:

(Get-CimInstance Win32_BaseBoard).Product

Verification Checklist

  1. Modes: Cycle through Eco → Balanced → Performance. Notice the fan acoustics adjust.
  2. Fans: Toggle Max Fan, try a custom 7-point curve, and test Manual sliders.
  3. Power & GPU: Test power gain (+15W) and MUX switch if offered by your BIOS.
  4. Lighting: Verify keyboard zone colors and dynamic lighting effects.
  5. Submit: Click Settings → Report Issue to automatically copy non-sensitive diagnostics and open a prefilled GitHub verification ticket.
